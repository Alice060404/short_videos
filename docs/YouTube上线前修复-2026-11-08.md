# YouTube 上线前修复（2026-11-08）

代码和部署配置已修复；正式站点未发布，服务器正式 Nginx、防火墙和服务配置未改变。真实浏览器交互仍因控制连接故障未完成，不应把本报告视作所有发布验收已通过。

## 已修复

- Nginx 模板将 `youtube/youtube.php` 纳入原有限流的 PHP 入口白名单，继续拒绝其他 `/api/` 路径。
- PHP 出站规则在内网拒绝之前，仅允许专用 svparser 用户访问 `127.0.0.1:8765/TCP`。
- 增加 `deploy/youtube/`：版本化虚拟环境准备脚本、独立 svyoutube 用户的 systemd 服务、专用出站规则和发布/回滚步骤。服务只绑定本机，限制 512 MiB、CPU 100%、64 个任务；停止时清理整个服务控制组。
- 新发现并修正依赖兼容性：2026.10.26 的 Requires-Python 是 >=3.11，us 只有 3.10.12。依赖统一固定为可安装且已复测的 yt-dlp 2026.10.21，无需升级服务器系统 Python。
- 长视频时长由 `266:52` 改为 `4:26:52`，同时处理小时边界和非有限值。
- 更新项目 README 和 YouTube 说明，移除“未接入网页”的过时描述。
