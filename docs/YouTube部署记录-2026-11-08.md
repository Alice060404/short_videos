## 发布过程与回滚

第一次激活时，Nginx 异步 reload 尚未完成，新请求仍被旧入口白名单拒绝，自动回滚成功。已将发布脚本改为轮询新路由返回预期 400 后才做视频验收；第二次发布通过。同时显式规范站点文件/目录权限为 0644/0755，避免 Windows 打包权限传播。

发布包、日志、备份：`/root/short-videos-deploy/20261108-youtube-132246/`，备份目录 `backup/`，包含旧 Nginx、旧 PHP 出站脚本、原服务配置存在状态和原 release 路径。

如需回滚，在 us 上执行：

```sh
python3 /root/short-videos-deploy/20261108-youtube-132246/run.py --rollback
```

回滚恢复到 `/var/www/short-videos/releases/20261106-04-security` 及其配套配置，停止新服务。保留发布目录和备份，避免误删回滚资源。
